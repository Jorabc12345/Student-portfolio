## 5. Possible MED 102 Options for Client Consideration

These are discussion alternatives only. None is an approved requirement.

### Option A – Client-defined academic groupings

The client supplies four folder names and assigns each of the eight domains according to the intended curriculum organization. This is the preferred option because it avoids developer assumptions.

### Option B – Four thematic groupings

The client may define four thematic folder names and assign domains according to curriculum themes. The grouping must be supplied or approved by the client before it is recorded as structure.

### Option C – Four administrative containers

The client may use four neutral containers while keeping all eight domains as independently visible nested learning units. This preserves the domains without claiming an academic relationship that has not been approved.

These options do not assign domains and must not be implemented as approved mappings without client confirmation.
