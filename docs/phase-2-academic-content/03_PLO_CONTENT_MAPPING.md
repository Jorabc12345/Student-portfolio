# Program Learning Outcomes Content Mapping

Phase 2 – Stage 3

## 1. PLO Organization

The portfolio contains one global Program Learning Outcomes section outside the twelve subject folders. It provides documentation areas for all eleven official BukSU-COM PLOs.

Each PLO entry should support:

1. The official PLO statement.
2. One or more student-selected supporting artifacts where relevant.
3. An artifact description explaining relevance and significance.
4. A short student reflection connecting the evidence to the outcome.

The source requires evidence documentation but does not define fixed subject-to-PLO relationships. Students may associate an artifact with one or more relevant PLOs; the system must not invent or enforce predetermined mappings.

## 3. PLO Evidence Entry Pattern

For each PLO, the student may provide:

- Artifact title and protected supporting file or image.
- Artifact description and explanation of significance.
- Subject and period/domain context, where applicable.
- Short reflection on how the evidence relates to the PLO.
- Optional link to the original reflection entry.
- Optional association with other relevant PLOs.

The artifact description and short reflection are source-required documentation elements. The other context links are organizational metadata that support traceability.

## 4. Multiple-PLO Evidence

One artifact may support multiple PLO entries when the student explains the relevance separately for each outcome. Each associated PLO should have its own:

- Relevance explanation.
- Short reflection.
- Context, if different from another PLO association.

The artifact itself should not be duplicated unnecessarily. No artifact automatically establishes formal attainment of any PLO.

## 5. PLO and Subject Relationships

The college instructions do not prescribe a fixed mapping between MED 101, MED 102, MED 103, or their learning units and individual PLOs. Therefore:

- No subject is preassigned to a PLO.
- No MED 102 domain is preassigned to a PLO.
- The student selects relevant PLO associations based on their evidence.
- The portfolio records evidence and reflection; it does not formally assess or declare PLO attainment.

## 6. Evidence Quality and Integrity

PLO evidence must follow the source-wide standards:

- Authentic to the student’s actual work, experience, or contribution.
- Relevant to one or more PLOs.
- Accompanied by reflective significance.
- Professionally presented.
- Free of patient-identifiable information.
- Supported by required permissions for clinical or community material.
- Transparent about references, collaborators, and artificial-intelligence use.

## 7. PLO Navigation Placement

The PLO section is a separate portfolio-wide section. It may link to subject reflections and artifacts, but it is not one of the twelve main subject folders and must not be used to invent a subject-folder mapping.
