# Final Visual Design System

## Palette

- White `#FFFFFF`: reading surfaces and primary canvas, approximately 60%.
- Pink `#FF669B`: identity, selected navigation, emphasis, approximately 30%.
- Butter yellow `#F9E7A2`: reflective callouts and gentle attention, approximately 10%.
- Dark ink, muted text, borders, focus, and semantic colors are functional accessibility tokens.

Use dark ink on pink/yellow surfaces where white text does not provide sufficient contrast. Do not use the brand colors as the sole status signal.

## Type and Layout

Use a readable sans-serif hierarchy with 16px minimum body text, 17px or larger long-form reflection text, 1.6–1.7 line height, and 65–75-character reading measure. Use 4/8/12/16/24/32/48/64 spacing, 8px control radius, and restrained shadows.

## Components

Buttons, forms, cards, navigation, breadcrumbs, prompts, editors, upload progress, artifact rows, feedback panels, dialogs, alerts, empty states, and loading states use consistent focus, error, and ownership presentation.

## Motion and Accessibility

Use brief purposeful Framer Motion transitions and respect reduced-motion preferences. Provide semantic headings, visible focus, keyboard access, labelled controls, error association, screen-reader announcements, and readable contrast.
