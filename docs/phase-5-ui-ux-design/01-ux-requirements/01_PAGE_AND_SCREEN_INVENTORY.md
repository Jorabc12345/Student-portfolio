# Page and Screen Inventory

## Shared and Authentication

1. Welcome / private portfolio entry.
2. Student registration.
3. Instructor registration with shared invitation-code field.
4. Login.
5. Password recovery and reset.
6. Session-expired and unauthorized access screens.

## Student Screens

1. Student dashboard / portfolio home.
2. Profile and All About Me.
3. Home Page editor: introduction, portrait, Learning Philosophy, My Why, The Good Doctor.
4. Level 1 overview.
5. Subject overview.
6. Main-folder overview.
7. Learning-domain view, including independent MED 102 domain navigation.
8. Reflection prompt and answer editor.
9. Artifact library.
10. Artifact upload and metadata form.
11. Artifact detail and association manager.
12. PLO Attainment overview and evidence editor.
13. Final Musings overview and response editor.
14. Portfolio progress/section completion view, if approved.
15. Instructor access management: active grants, grant flow, revoke flow.
16. Reviews and feedback inbox/detail.
17. Account and privacy settings.

## Instructor Screens

1. Instructor dashboard with only authorized portfolios.
2. Authorized portfolio list/search, without a public directory.
3. Read-only portfolio viewer.
4. Subject/folder/domain viewer.
5. Reflection and artifact viewer.
6. Review creation/edit view, subject to approved lifecycle.
7. General and item-linked feedback composer.
8. Review/feedback history.
9. Instructor profile and account settings.

## Client Administrator Screens

1. Restricted administrator login.
2. Invitation-code status screen.
3. Generate/reveal current shared code.
4. Replace current code.
5. Disable current code.
6. Code lifecycle confirmation/history, without historical plaintext values.

The administrator screen inventory is intentionally narrow and does not include a general user, portfolio, curriculum, or grading dashboard.
