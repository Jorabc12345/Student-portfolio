# UI/UX Unresolved Decisions

## Conflicts Requiring Reconciliation

1. Existing Phase 3 documents call faculty read-only with no feedback; the revised database model permits authorized instructor reviews and feedback.
2. Existing architecture wording describes trusted assignment; the revised model uses student-controlled portfolio authorization.
3. Existing architecture names a faculty dashboard, but its exact review/feedback behavior requires the revised policy.

## Client or Institutional Decisions

- Final visual identity, logo, colors, and typography.
- Whether student portfolio access authorization uses instructor email, account search, invitation link, or another controlled lookup.
- Whether students may revoke access immediately while an instructor is viewing.
- Review and feedback edit/delete rules and whether published records are immutable.
- Whether students can reply to or acknowledge feedback.
- Whether progress/completion is shown and what it means.
- Exact artifact formats, size limits, retention, and deletion messaging.
- Backup/availability messaging visible to users.
- Final MED 102 folder labels and final navigation labels.
- Final MED 103 navigation labels.
- Whether client administrator functionality is a separate role/shell or a restricted operational screen.

## Accessibility and Content Decisions

- Approved language for privacy/confidentiality warnings.
- Required screen-reader wording for academic prompts and upload status.
- Keyboard and mobile support baseline.
- Whether autosave is permitted or only explicit save.

No unresolved item is silently treated as approved.
