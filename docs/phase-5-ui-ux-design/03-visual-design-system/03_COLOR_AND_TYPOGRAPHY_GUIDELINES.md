# Color and Typography Guidelines

## Color Use

| Purpose | Color |
|---|---|
| Page and reading background | White |
| Main identity/navigation | `#FF669B` |
| Selected navigation and primary emphasis | Pink with dark ink text where needed |
| Reflective callouts and gentle reminders | `#F9E7A2` |
| Primary text | `#2D2430` |
| Secondary text | `#665C66` |
| Dividers | `#E8DDE2` |
| Focus | `#8A3156` |
| Success/error/warning | Semantic colors with text/icon labels |

Do not use pink or yellow as the only status indicator. Do not place long body text in saturated pink or yellow.

## Typography

Font choice remains a proposed design decision; use a readable system sans or approved humanist sans. A proposed hierarchy is:

- Display: 32px / 1.2, semibold.
- Page heading: 28px / 1.25, semibold.
- Section heading: 22px / 1.3, semibold.
- Card heading: 18px / 1.35, semibold.
- Body: 16px / 1.6.
- Long-form reflection: 17px / 1.7, measure 65–75 characters.
- Supporting text: 14px / 1.5.
- Labels and controls: 14–16px / 1.4, medium.

Use sentence case, informative headings, and official academic question wording without decorative shortening.

## Spacing, Radius, and Shadow

- Spacing scale: 4, 8, 12, 16, 24, 32, 48, 64px.
- Control radius: 8px.
- Cards and panels: 12px.
- Large page sections: 16px.
- Default shadow: `0 2px 8px rgba(45,36,48,.08)`.
- Elevated dialog shadow: `0 12px 32px rgba(45,36,48,.16)`.

Borders should carry structure before shadows do.
