# Accessibility Guidelines

## Visual

- Verify text and control contrast against white, pink, yellow, and tinted surfaces.
- Use dark ink on pink/yellow surfaces where white text fails.
- Maintain visible keyboard focus using the focus color and an outline, not only a shadow.
- Do not communicate status with color alone.

## Structure and Interaction

- Use semantic headings in academic order.
- Associate every label, helper text, and error with its control.
- Provide keyboard access to navigation, tabs, dialogs, upload controls, and editors.
- Trap focus in dialogs and return focus to the triggering control.
- Use screen-reader announcements for save, upload progress, upload failure, revoke success, and authorization errors.

## Long-Form Writing

- Provide adequate line height, resize-friendly text areas, and comfortable reading width.
- Preserve prompt/question context while scrolling when possible.
- Do not rely on placeholder text for required instructions.

## Privacy and Safety

- Avoid exposing private portfolio details in browser titles, notifications, previews, or unauthorized error messages.
- Clearly warn against patient-identifiable artifacts.
- Ensure read-only instructor views are announced and visually apparent.
- Support reduced motion and responsive zoom without loss of content or action access.
