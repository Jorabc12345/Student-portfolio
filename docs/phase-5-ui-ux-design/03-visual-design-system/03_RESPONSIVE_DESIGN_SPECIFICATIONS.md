# Responsive Design Specifications

## Desktop

- 240–280px sidebar with role-specific navigation.
- Main content max-width 1200px.
- Reflection reading measure 65–75 characters.
- Split prompt/editor layout where space permits.
- Tables become structured lists when columns become crowded.

## Tablet

- Collapsible sidebar and persistent top bar.
- Two-column layout only for prompt/context plus editor when comfortable.
- Stack artifact metadata and association controls.
- Keep breadcrumbs and selected academic context visible.

## Mobile

- Single-column layout.
- Menu drawer replaces sidebar.
- Bottom or top compact navigation for Home, Level 1, Artifacts, and More.
- Long prompts remain readable with generous line height.
- Primary save/upload/revoke actions remain visible and thumb reachable.
- Dialogs use nearly full width with clear cancellation.

## Cross-Device Behavior

Do not hide required questions, domain identity, privacy notices, or authorization status at smaller widths. Preserve drafts and unsaved-change warnings across responsive layout changes.
