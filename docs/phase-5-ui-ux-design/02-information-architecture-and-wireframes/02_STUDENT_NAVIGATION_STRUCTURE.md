## Context Navigation

Use breadcrumbs such as `Level 1 / MED 102 / Domain / Reflection`. A domain may be reached from its folder or directly from the MED 102 domain index. Artifact associations should return the student to the originating reflection or domain context.

## Access and Feedback

Instructor Access lists active/revoked authorizations and provides grant/revoke actions. Reviews and Feedback is read-oriented; original student content remains in its academic location.
