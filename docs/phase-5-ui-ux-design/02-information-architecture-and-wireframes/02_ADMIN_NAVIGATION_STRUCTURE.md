# Client Administrator Navigation Structure

## Scope

The administrator experience is limited to the shared instructor invitation code. It is not a general administration dashboard.

```text
Administrator
├── Invitation Code Status
├── Generate / Reveal Current Code
├── Replace Current Code
├── Disable Current Code
├── Lifecycle Confirmation
└── Logout
```

Replacing or disabling the code blocks future instructor registration but does not change existing instructor accounts or student-granted portfolio authorizations.
