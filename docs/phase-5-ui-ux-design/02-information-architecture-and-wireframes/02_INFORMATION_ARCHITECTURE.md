# Information Architecture

## Structural Principles

- The portfolio is organized around academic reflection, not tasks or scores.
- Home Page is the personal entry point; Level 1 is the academic entry point.
- Subject → folder → domain/prompt context remains visible while editing.
- PLO Attainment and Final Musings are global Level 1 sections.
- MED 102 domains remain separately addressable; proposed folder grouping is a navigation aid only.
- Instructor review/feedback is additive and visually separate from student originals.

## Content Hierarchy

```text
Portfolio
├── Home Page
├── Academic Level
│   ├── Subject
│   │   └── Main Folder
│   │       ├── Learning Domain
│   │       ├── Reflection Prompt/Answer
│   │       └── Artifact Associations
│   ├── PLO Attainment
│   └── Final Musings
├── Artifact Library
├── Instructor Access
└── Reviews and Feedback
```

## Page Context

Every academic detail page should identify the current level, subject, folder, domain, and prompt where applicable. Mobile layouts may collapse the sidebar, but must retain breadcrumbs or an equivalent context trail.

## Ownership Presentation

Student-authored content uses an editable presentation. Instructor viewing uses a read-only presentation with no edit/delete/upload controls. Instructor feedback uses an unmistakable guidance style and attribution.

## Search and Filtering

Search is limited to the user's authorized portfolio context and should not become a public directory. If search is not approved, navigation and filters are sufficient for Version 1.
